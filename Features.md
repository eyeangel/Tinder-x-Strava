### Features

-- Mobile app UI mockup, a limited-time collaboration screen between a dating app and a fitness tracking app. 

-- A toggle filter at the top for 'Runners,' 'Cyclists,' 'Hikers' to match preference by activity type. 

-- Dark mode.

-- Typography: modern sans-serif. 
<br></br>

#### Home page

-- Swipe-card interface styled like Tinder, but with fitness activity data integrated into user profiles. 

-- Top of screen: a co-branded banner reading 'Sweat Week' campaign badge in a gradient, blending Tinder's signature red/pink with Strava's orange, positioned as a limited-time event ribbon. 

-- Each profile card shows a user's photo alongside a small stats overlay in the bottom corner: a route map thumbnail, a pace/distance badge (e.g. '5K • 24:10'), and a small verified-activity checkmark icon.
<br></br>

#### Match Success page

-- The success screen includes the celebratory match state, shared activity options, and a first-challenge preview.
<br></br>

#### Chat page

-- The chat screen includes the conversation thread, embedded “SUNSET 5K” challenge card, progress state, acceptance action, typing indicator, and message composer.
<br></br>

#### Group meetup page

-- Extended chat UI with activity selection, match invitations, time and route planning, a crew summary, invite preview, and group-chat creation.
<br></br>

#### Badges page

-- Badge-system. Examples of badges includes joint milestone badges.

-- An optional Verified mover profile badge that communicates synced activity history.

-- Includes a section for hosted events.
